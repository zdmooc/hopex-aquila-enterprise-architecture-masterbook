## Ce que vous devez savoir faire après cette partie

Vous devez être capable de :

- cadrer une décision de Business Architecture ;
- distinguer capability, process, organization, service et value stream ;
- construire une capability map cohérente ;
- relier value streams et customer journeys ;
- construire un business service catalog ;
- maintenir une process architecture de haut niveau ;
- identifier les business information objects ;
- relier stratégie → business → IT ;
- produire capability/application et capability/org matrices ;
- conduire assessments et gap analysis ;
- construire current/transition/target ;
- produire une roadmap orientée outcomes ;
- défendre la transformation devant un Architecture Board.
